# دعوة عقيقة الأميرة تاليا

مشروع React + Vite جاهز للتطوير والنشر على Vercel.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

## إضافة أغنية تاليا
ضع ملف الأغنية بصيغة MP3 في:
`public/music/talia-song.mp3`

يجب أن يكون اسم الملف مطابقًا تمامًا. التشغيل يبدأ بعد ضغط الزائر على «افتحوا دعوتنا» لأن المتصفحات تمنع التشغيل التلقائي قبل تفاعل المستخدم.

## النشر على Vercel
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. من Vercel اختر Add New Project واربط المستودع.
3. اترك إعدادات Vite الافتراضية: Build Command `npm run build` و Output Directory `dist`.
4. انشر المشروع.
